CFP.dev API Token

Imports require a token because the public API omits fields needed for complete banners. The token lets the importer read authenticated CFP.dev profiles for job titles and additional portrait URLs. The token is kept in memory for this server process only.

Sign in to your CFP instance, open the browser developer tools (F12) and select the Network tab. Reload the page, choose an authenticated request such as /api/account, and copy the value from the Authorization: Bearer … header. This application removes the Bearer prefix for you.

Endpoint patterns use your event ID, for example https://{eventId}.cfp.dev/api/public/speakers and https://{eventId}.cfp.dev/api/account. 

curl --url 'https://vdz27.cfp.dev/api/account' \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer <PASTE_YOUR_TOKEN_HERE>'

This token is shown in plain text and grants access to your CFP account. Do not commit it, paste it into issues, or share screenshots while it is visible.
